# Vasudha Devarakonda's portfolio

A static academic portfolio for GitHub Pages. The site uses plain HTML, CSS, and JavaScript; no build step is required.

## Local preview

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Push this repository to GitHub when you are ready to publish.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.

GitHub Pages will provide the published site URL in the Pages settings.
